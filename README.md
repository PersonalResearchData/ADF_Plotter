# ADF_Plotter
ADF_Plotter is a web tool to analysis for molecular dynamics simulation.
+ https://personalresearchdata.github.io/ADF_Plotter/

## How to use
1. Click the [ファイルを選択] button
![image](https://github.com/user-attachments/assets/91a2be14-31a1-4053-9816-ca1b88f625f4)

2. Select an *.xyz file
![image](https://github.com/user-attachments/assets/2a9f2f72-5277-46b4-8e84-5a49a6d41c48)

3. Set the radius and number of bins

4. Click Plot
![image](https://github.com/user-attachments/assets/3b384951-e6da-4cb8-b26b-86125cc27f79)
